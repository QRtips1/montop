# MonTop

https://montop.me/ — независимый гид по национальным паркам Черногории (GitHub Pages): главная с вкладками парков, `/lovcen/`, `/skadarsko-jezero/`, `/biogradska-gora/`, `/prokletije/`. Дурмитор живёт на https://durmitornationalpark.me/.

Собирается из исходников MonTop (`tools/build_hub.py`, `tools/build_park.py`, `tools/make_deploy.py`); руками здесь ничего не править.
